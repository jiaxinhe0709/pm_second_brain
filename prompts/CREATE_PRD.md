# Create a PRD

Create one PRD Markdown file from `templates/prd.md`.

- Search existing documents before assigning an ID.
- Use the next available ID for the product code.
- Capture the problem and desired outcome before prescribing a solution.
- Distinguish goals from non-goals.
- Make requirements individually testable.
- Record uncertainties under open questions.
- Keep `confluence.publish` set to `false` until publication is explicitly approved.
