### TEST Environment Processing Policies
Flexible Certificate Ingestion:
Flexible Certificate Ingestion: The compliance endpoint will accept test or simulation digital certificates. Cryptographic checking logic asserts that the certificate's structure and layout conform to standard X.509 formats without rejecting registrations due to unmatched tax-entity lookup records.
Validation Emulation:
Senders are required under national rules to ensure schemas match required structural frameworks before submission. In the TEST environment, our API runs complete code check evaluations, outputting descriptive logs without writing permanent data to the public repository
TEST
.
No Permanency Binding:
No Permanency Binding: Under Spanish e-invoicing parameters, starting live compliance processes locks an identity into automated tracking routines for that calendar cycle. The TEST state ensures no historical or tracking records persist, allowing teams to loop onboarding configurations iteratively without restriction
TEST
.
PRO Environment Processing Policies
Production Gatekeeping:
The
PRO
onboarding thread enforces a strict match between the uploading entity's NIF, the signature keys embedded in the uploaded administrative certificate, and verified registration details.
Live Handover Initialization:
Live Handover Initialization: Upon successful confirmation from the user application, the connection routing engine compiles the finalized business configuration profile and executes a permanent registration request directly against the live Spanish Public Platform network endpoints.
