# Security and Operations

## Purpose

This section groups the trust, identity, data, resilience, support and reconciliation capabilities required to operate the Phase 3 service safely across Sage, an operator or partner, the public solution and counterparty platforms.

The detailed PRDs remain authoritative. This page is a navigation and operational-boundary view.

## Capability coverage

| Capability from the Phase 3 assessment | Authoritative document | Current treatment |
|---|---|---|
| ISO/IEC 27001 or accepted equivalent | [Security — Trust, Identity, Data and Audit](https://confluence.sage.com/pages/viewpage.action?pageId=866148660) | Production evidence gate |
| Secure AS2/AS4 transport | [Security — Trust, Identity, Data and Audit](https://confluence.sage.com/pages/viewpage.action?pageId=866148660) | Covered; exact profiles remain external evidence |

## Boundary and open decisions

- Availability, recovery and support targets must be approved from evidence rather than assumed from the source capability list.
- Security certification, business continuity evidence and data governance are cross-cutting production gates.
- Customer-facing dashboards should receive their own PRD only if the experience, users and independently deliverable outcomes extend beyond the existing onboarding, lifecycle and incident views.
