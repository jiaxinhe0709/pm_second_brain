Customer actions: switching and offboarding

A switch changes the platform used to send or receive new invoices. Offboarding ends selected access or services. The customer starts one switch request; Sage coordinates new setup and any old-service exit. Earlier work still needs someone responsible for it.

Switching and offboarding: detailed checks

Switch setup uses existing onboarding APIs where suitable. Read the API mapping and Spain checks.
